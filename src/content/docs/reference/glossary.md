---
title: Glossary
description: Definitions of the terms used in DigitalVI Studio.
---

| Term | Meaning |
| --- | --- |
| API key | A secret token that lets another system use the Studio API as a particular user. See [Users](/clients/users/#api-keys). |
| App release channel | Which app updates a player receives: Production, Beta or Alpha. See [App versions](/players/app-versions/#release-channels). |
| Client | Your organization's account in Studio. |
| Collection | A folder for organizing playlists. |
| Data feed | Live content such as weather, RSS, clock, YouTube or a stream. See [Data feeds](/content/data-feeds/). |
| Device | Non-player hardware monitored or controlled by Studio. See [Devices](/control/devices/). |
| Display | A physical screen connected to a player. One player can drive several. |
| Event ID | A number used to trigger a playlist on demand. |
| Event playlist | A playlist that plays on demand rather than on a schedule. See [Event playlists](/playlists/playlist-groups/#event-playlists). |
| Fallback layout / playlist | What a playlist group shows when nothing is scheduled. |
| Hardware driver | Instructions that let a player or device talk to specific hardware. See [Hardware drivers](/control/hardware-drivers/). |
| Kiosk mode | Locks the device to the DigitalVI app. Needs a kiosk license. |
| Layout | How a screen is split into zones. See [Layouts](/players/layouts/). |
| Location | A place in your location tree. Controls time zone, settings and access. See [Locations](/players/locations/). |
| Main zone | The primary zone of a layout. Status and several controls refer to it. |
| Player | A screen or media device running DigitalVI. See [Players](/players/players/). |
| Playlist | An ordered list of media or data feeds. See [Playlists](/playlists/playlists/). |
| Playlist group | Players that share the same content. See [Playlist groups](/playlists/playlist-groups/). |
| Proof of play | Records of what played where and for how long. See [Display statistics](/players/display-statistics/). |
| Provisioning code | A code used to pair a physical device with a player record in Studio. |
| Role | A named set of permissions. See [User roles](/clients/user-roles/). |
| Schedule | A rule for when a playlist or layout is active. See [Scheduling](/reference/scheduling/). |
| Single website mode | Makes a player show one website full-time. |
| Synchronization | Automatic import of files from Google Drive into a playlist. See [Synchronizations](/playlists/synchronizations/). |
| Tag | A label for matching media to players. See [Tags](/players/tags/). |
| User permission | A user + location + role assignment. See [User permissions](/clients/user-permissions/). |
| Zone | A rectangular area of a layout that plays its own playlist. |
