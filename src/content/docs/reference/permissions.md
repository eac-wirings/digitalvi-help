Permissions are ticked on a [user role](/clients/user-roles/) or on a
[user permission](/clients/user-permissions/) with *Custom permissions*. Every permission applies to the chosen
location and all locations below it.

## Clients

| Permission | Allows the user to |
| --- | --- |
| Manage users | Add, edit and deactivate [users](/clients/users/), and grant [user permissions](/clients/user-permissions/). |
| Manage roles | Create and edit [user roles](/clients/user-roles/). |

## Customer notifications

| Permission | Allows the user to |
| --- | --- |
| View customer notifications | Read [Messages](/home/messages/). |
| Manage customer notifications | Create and manage notifications. |

## Dashboards

| Permission | Allows the user to |
| --- | --- |
| View dashboards | See the [Dashboard](/home/dashboard/) and [location dashboards](/players/locations/#location-dashboard). |
| Manage dashboards | Edit location dashboards. |

## Devices

| Permission | Allows the user to |
| --- | --- |
| View hardware drivers | See [Hardware drivers](/control/hardware-drivers/). |
| Manage devices | Add and edit [Devices](/control/devices/). |

## Layouts

| Permission | Allows the user to |
| --- | --- |
| Manage layouts | Create, edit and delete [layouts](/players/layouts/), and use the [layout builder](/players/layout-builder/). |

## Licenses

| Permission | Allows the user to |
| --- | --- |
| View licenses | See [Licenses](/players/licenses/). |
| Manage licenses | Change licenses. |

## Locations

| Permission | Allows the user to |
| --- | --- |
| View locations | See [Locations](/players/locations/). |
| Add location notes | Edit the note on a location, without other changes. |
| Manage locations | Create, edit and delete locations, and edit opening hours. |

## Messages

| Permission | Allows the user to |
| --- | --- |
| Send messages | Send messages to other users. |

## Players

| Permission | Allows the user to |
| --- | --- |
| View players | See [Players](/players/players/) and player pages. |
| View only map on dashboard | See only the map on the dashboard, without the status tiles. |
| Reboot players | Use **Reload application** on a player. |
| Manage players | Edit players. |
| Admin players | Use the player **Admin** menu (change client, displays, logs, single website mode). |
| (De)activate players | Deactivate and reactivate players. |
| Add new players | Create players. |
| View display statistics | See [Display statistics](/players/display-statistics/). |
| Manage player users | Manage the local user accounts on players (the player's web interface). |
| Manage player settings | Change [player settings](/reference/player-settings/) on locations and players. |
| View app versions | See [App versions](/players/app-versions/). |

## Playlist groups

| Permission | Allows the user to |
| --- | --- |
| Manage playlist groups | Create and edit [playlist groups](/playlists/playlist-groups/), fallbacks, event playlists and schedules. |

## Playlists

| Permission | Allows the user to |
| --- | --- |
| View playlists | See [Playlists](/playlists/playlists/). |
| Manage media | Upload and manage files in the [Media manager](/playlists/media-manager/). |
| Manage playlists | Create, edit and delete playlists. |
| Manage synchronizations | Set up [Synchronizations](/playlists/synchronizations/). |
| Content creation | Use [Content creation](/content/content-creation/). |
| Manage Data feeds | Create and edit [Data feeds](/content/data-feeds/). |

## Tags

| Permission | Allows the user to |
| --- | --- |
| Manage tags | Manage [Tags](/players/tags/) and bulk-tag players. |
