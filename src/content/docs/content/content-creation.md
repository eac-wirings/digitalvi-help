**Where:** Content → Content creation (`/contentCreation`)

Content creation opens **Photopea**, a full image editor similar to Photoshop, inside Studio. You can design a
slide, menu board or promotion and send it straight to a playlist, without switching to another program.

![Content creation](/screenshots/content-creation.png)

## Create a design

1. Click **New Project** and set the canvas size to match your layout zone. For a full-screen landscape display
   that's **1920 × 1080**; for portrait it's **1080 × 1920**.
2. Or click **Templates** to start from a ready-made design, or **Open From Computer** to edit an existing
   file. Photopea opens PSD, AI, XD, Figma, Sketch, PDF, RAW and common image files.
3. Design your content.

## Save to a playlist

When you save, Studio shows the **Save to playlist** dialog:

| Field | Description |
| --- | --- |
| File name | The name the image will have in Studio. |
| Playlist | The [playlist](/playlists/playlists/) to add it to. |

Click **Save**. The image is uploaded to your media and added to the end of that playlist.

:::tip
Keep your original design file (for example `.psd`) on your computer or in cloud storage, so you can edit it
later. Studio stores the exported image.
:::

## Permissions needed

**Content creation**.
