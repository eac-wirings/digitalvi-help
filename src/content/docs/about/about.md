**Where:** About → About (`/about`)

Shows which version of DigitalVI Studio you're using. Include it when you contact [support](/about/support/).

![About page](/screenshots/about.png)

| Item | Example |
| --- | --- |
| Product | Studio: digital signage management server |
| Server version | 1.8.16 |
| Contact | https://DigitalVI.app, support@digitalvi.app |

The server version also appears on error pages, together with the request URL and a timestamp.
