**Where:** About → Support (`/support`)

The Support page shows the support contact information for your organization.

![Support page](/screenshots/support.png)

## Ways to get help

| Option | How |
| --- | --- |
| Email | [support@digitalvi.app](mailto:support@digitalvi.app) |
| In-app feedback | Click your name (top-right) → **Provide feedback** to send a message or bug report to the DigitalVI team. |
| Tutorials | Home → [Tutorials](/home/tutorials/) for guided walk-throughs inside Studio. |
| This help site | Search with the box at the top of any page. |

## When reporting a player problem

Include this information so we can help faster:

1. The **player name**, and a link to its page in Studio.
2. What you expected to see and what is actually on screen. A screenshot helps: on the player page, click the
   **camera icon**.
3. The player's logs: open the player and choose **Admin → Download logs**. This collects the logs, a
   screenshot and the configuration as a ZIP file. See [Player details](/players/player-details/#admin-menu).
